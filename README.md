# Bedwars Toolbox

A utility mod for Minecraft Forge 1.8.9 focused on enhancing the Hypixel BedWars experience.

## Features

Current and planned features include:

* TNT countdown timer
* Invisibility footprint indicators
* Sharpness particle indicators
* BedWars star display
* Generator timer HUD
* Block highlight overlays
* Player statistics overlays
* Additional quality-of-life improvements

## Installation

1. Install Minecraft Forge 1.8.9.
2. Download the latest Bedwars Toolbox release.
3. Place the `.jar` file into your `.minecraft/mods` folder.
4. Launch Minecraft using the Forge profile.
